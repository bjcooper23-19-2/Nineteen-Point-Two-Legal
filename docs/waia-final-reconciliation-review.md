## Canonical WAIA Terms amendment specification

Apply these targeted edits to `WAIA-Marketing-Site/terms/index.html` in a separate reviewed change. Preserve existing customer responsibility, AI limitations, Customer Data and IP ownership, licence restrictions, acceptable use, security and suspension protections, and the current section 23 financial liability allocation pending solicitor review.
